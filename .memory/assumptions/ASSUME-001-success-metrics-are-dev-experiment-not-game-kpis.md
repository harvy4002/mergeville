## Assumption

Because mergeville has no monetization, no target user base, and no launch plan, "success" is defined in terms of the AI-assisted solo-development experiment (e.g. how much of the game can be built and kept coherent via AI assistance, development velocity, whether the core/idle/meta loop is fun to play at all) rather than conventional mobile game KPIs (DAU, D1/D7/D30 retention, ARPU, ad fill rate, etc.).

## Context

Raised while drafting `.memory/product-vision.md`. The user confirmed (during `/init-project`) this is "a test project to see what can be coded into a mobile game using AI" with no ads/IAP. The standard vision template's "Product Goals & Outcomes" and "Success Metrics" sections assume a real product with a user base, so this assumption substitutes experiment-oriented goals in their place.
